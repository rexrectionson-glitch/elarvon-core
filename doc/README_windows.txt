ELARVON Core
============

Intro
-----
ELARVON is an open-source peer-to-peer digital value network. Users control
their wallet keys and transact directly over the ELARVON network.


Setup
-----
Install the application and run elarvon-qt.exe.

ELARVON Core downloads and verifies the ELARVON blockchain. Initial
synchronization time depends on the computer and network connection.

Explorer and network information:
  https://elarvonexplorer.com
